Подготовка к защите Assignment 5

1. HTML задаёт структуру: заголовки, абзацы, формы, списки и кнопки.
CSS отвечает за оформление. JavaScript меняет страницу и реагирует на действия.

2. Скрипты подключены через script src с defer. Они выполняются после чтения HTML.
Сначала загружается student.js, затем скрипт конкретной страницы.

3. getElementById и querySelector находят элементы DOM. DOM — представление
HTML-документа в виде дерева объектов, с которым может работать JavaScript.
textContent изменяет текст. style.backgroundColor и style.fontSize меняют стили.

4. let объявляет переменную; const — переменную, которую нельзя переназначить.
Строка содержит текст, number — число, boolean — true или false.
Оператор + складывает числа или соединяет строки.

5. addEventListener привязывает функцию к событию.
click — нажатие; mouseover — наведение; mouseout — уход мыши;
keyup — отпускание клавиши; submit — отправка формы;
change — изменение состояния checkbox.

6. createElement создаёт элемент. appendChild добавляет его в DOM.
removeChild удаляет дочерний элемент. Перед удалением проверяем,
существует ли последний элемент, чтобы не получить ошибку.

7. Значение input.value — строка. Number переводит её в число.
switch выбирает арифметическую операцию. Деление на ноль проверяется отдельно.
preventDefault отменяет обычную отправку формы, чтобы страница не перезагрузилась.

8. В To-Do tasks — массив объектов {text, completed}.
push добавляет объект, splice(index, 1) удаляет один объект.
forEach перебирает массив. showTasks заново создаёт список по данным массива.
Checkbox меняет completed, а CSS text-decoration: line-through зачёркивает текст.
После удаления список создаётся заново, поэтому индексы обработчиков актуальны.
После перезагрузки массив пустой: постоянное хранение не используется.
trim убирает пробелы по краям и помогает отклонять пустые задачи.
textContent показывает введённое пользователем как текст, а не как HTML.

Практика перед защитой:

— добавить ещё один элемент через createElement;
— объяснить каждый обработчик;
— добавить новую арифметическую операцию;
— показать, где добавляется, удаляется и завершается задача.
